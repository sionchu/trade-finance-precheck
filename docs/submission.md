# 기업 수출거래 Treasury 사전점검

## 한 문장

AI가 계약서·PO와 재무제표를 읽어 거래와 회사의 금융 상태를 구조화하고, 결정론적 엔진이 회사 전체 유동성·자금조달·외화노출·대응 조건을 계산하며, 읽기 전용 거래 검토 Agent가 검증된 근거만 연결해 설명한다.

## 해결 문제

계약의 수익성만 보지 않고 회사의 기존 자금계획까지 합쳤을 때 실제로 그 거래를 버틸 수 있는지를 본다. 거래만 보면 한도 안에 들어오는 경우에도 같은 날짜의 급여·세금·설비대금 등을 더하면 회사 전체 유동성 부족이 커질 수 있다.

## 주요 사용자

수출입 중소·중견기업의 재무·자금·Treasury 담당자와 Corporate RM, Transaction Banking, Trade Finance, FX desk 상담을 준비하는 실무자.

## 구현 기능

- 계약서·PO에서 지원 거래 사실을 추출하고 사용자가 확인한 항목만 현재 거래에 반영
- 재무제표에서 아홉 가지 단기 유동성 사실을 추출하되 거래 투입가능자금을 자동 산정하지 않음
- 마진, 거래 현금흐름, 자금소요, 복합 악화 시나리오, USD/KRW 기준점, 목표마진 충족 조건 계산
- 직접 입력 또는 표준 CSV ERP export로 회사 자금계획을 구성하고 prospective Deal 현금흐름을 같은 달력에 overlay
- 이번 거래에 필요한 외부자금, 회사 전체 최대 자금부족, 현재 한도 반영 후 부족 비교
- 회사자금·기존 운전자금·매출채권 현금화 비교
- USD·JPY 통화별 수취·지급·금액 기준 상계·열린 노출과 사용자 입력 선물환 시뮬레이션
- 한 외화 지급건의 Banker's Usance 조달 가정과 일반 운전자금 한도 부담·총 은행 원금 노출 비교
- 정확히 네 개의 읽기 전용 근거 도구를 두 번의 모델 요청으로 읽는 단일 거래 검토
- 현재 결정론적 근거와 현재 거래 검토만 포함하는 인메모리 PDF 보고서
- 화면 내 `용어·사용법` 도움말에서 5단계 절차와 주요 금융용어·계산 경계를 클릭해 확인

## 사용자 흐름

1. 거래 정보
2. 회사 자금
3. 시나리오 분석
4. 대응안 비교
5. 종합 진단

직접 입력 또는 판매계약·USD/JPY 공급자 PO PDF로 거래를 확인한다. 회사의 현재 현금·한도·금리를 입력하고 기본 진단을 계산한다. 목표마진·환율·금리·회수지연 시나리오를 명시적으로 계산한 뒤 대응조건의 현재·대안·변화를 비교하고, 종합 진단에서 선택적으로 짧은 거래 검토와 보고서를 확인한다.

## AI 역할

1. Trade Document Financialization: 비정형 거래문서에서 지원 사실만 구조화
2. Financial Statement Financialization: 재무제표에서 단기 유동성 사실만 구조화
3. Single Deal Review Agent: 이미 계산된 현재 근거를 읽고 검토 의미를 간결하게 설명

AI는 금융 숫자를 계산하거나 거래·대출·헤지 실행을 결정하지 않는다.

## 결정론적 계산

Financial Engine과 별도 frozen overlay가 Deal economics, Company Liquidity Timeline, Funding Choice, FX Treasury, Banker's Usance, Deal Rescue를 계산한다. 사용자의 거래·회사자금·한도·환율·금융조건 입력이 계산의 기준이다.

## 데이터

- 가상의 계약서·PO·재무제표 PDF
- 가상의 표준 ERP 자금계획 CSV
- 사용자가 명시적으로 불러온 경우에만 표시되는 K-SURE 국가·업종 결제완료 집계정보

## 심사위원 검증 방법

1. 공개 앱의 `거래 정보`에서 직접 입력 또는 샘플/PDF 문서를 선택한다.
2. `회사 자금`에서 현재 현금·한도·실제 조달금리와 기본 회사 자금계획을 확인하고 `기본 진단 계산`을 누른다.
3. 이번 거래에 필요한 외부자금 `6,900만원`, 회사 전체 최대 자금부족 `8,900만원`, 현재 한도 반영 후 부족 `1,900만원`을 비교한다.
4. 가장 부족한 날 `2026-11-03 / D+60`을 확인한다.
5. `시나리오 분석`에서 환율·금리·회수지연 중 하나를 바꾸고 `시나리오 계산`으로 기본→시나리오→변화를 확인한다.
6. `대응안 비교`에서 현금화·헤지비율·Usance 만기 중 하나를 조절하고 현재→대안→변화를 확인한다.
7. `종합 진단`에서 계산값을 먼저 확인하고 거래 검토를 한 번 실행한 뒤 우선 검토 주제, 함께 본 근거, 실제 사용한 네 도구를 확인한다.
8. 현재 조건의 최종 보고서를 다운로드한다.
9. 각 단계 아래 `용어·사용법`을 열어 절차와 주요 금융용어 설명을 확인할 수 있다.

재무제표 AI와 K-SURE 불러오기는 선택 기능이며 위 핵심 결정론적 경로에 필수는 아니다.

## 제한 / Non-goals

은행 승인·신용평가, 금융상품 실행, 환율 전망, 바이어 부도 예측, 최적 상품 추천, 완전한 L/C·UPAS·D/A·D/P 업무, 실시간 SAP 연결, 회계·TMS·ERP 대체를 제공하지 않는다.

## 외부 데이터 공개

공개 MVP의 선택적 외부 데이터는 K-SURE 국가·업종 결제완료 집계정보뿐이다. 문서·재무제표 AI와 거래 검토에는 OpenAI API가 명시적 사용자 행동 때만 사용된다. 한국수출입은행 환율 adapter는 공개 배포에서 비활성화되어 있으며 실시간 은행·ERP 연결은 없다.
